# V2: Cut From the MVP

Nothing here gets built until every Phase 5 "Done when" item is ticked.

## From the guide's MVP exclusions
- Display on the controller
- Battery gauge beyond the low-battery LED
- Pairing with multiple phones
- Custom app icon work
- App Store listing
- Sound
- Haptics in the controller
- Dedicated focus wheel

## Cut during Phase 1
- **Manual focus:** a hold-button + dial combination for lens position, to replace the missing focus wheel.
- **Auto ISO in Manual:** hold ISO + front dial to toggle Auto ISO in M mode, if the format supports it.
- **User-set ISO in A and S modes:** the Nikon behavior. It depends on which combinations `supportsExposureModeCustom` accepts on the 18 Pro.
- **White balance:**
  - Fine Kelvin adjustment (hold WB + front dial, 100 K steps)
  - Tint control
- **More buttons:** AE-L, AF-ON, a function button, playback. These need an I²C port expander, because D0–D10 are all used.
- **Exposure:**
  - Accelerated dial steps on a fast spin
  - An option for aperture in the 4 recommended full stops instead of thirds
  - Wrap-around at the ends of value lists
- **Handling:**
  - Left-handed grip
  - Cage mount (1/4-20 + cold shoe)
  - MagSafe plate
- **User settings:** remappable controls, such as swapping dial directions in the app.
